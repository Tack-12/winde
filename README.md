# WINDE

Hello there kind stranger in the internet , I welcome you to my twist on the
popular text editor project by antirez's Kilo.

The Text Editor is an opinionated open source text editor written in C. I do not
intend this project to be a wellbuilt drop-in replacement text editor; rather it
is a simple extension of Kilo that adds personal flavor to the editor.
You can use the code and edit it further to suit your needs or even learn
from tinker the code within it.

## PERSONAL GOAL

- I intend to build Winde as a project overtime and polish it to a point where I
  feel comfortable with using it as a text editor.
- Winde will be a simple text editor that will be polished over time with new features
  and improvements as I dive deeper into the text editor realms.
- Intended to be a text editor without any AI assistance however you can add AI
  extensions to enhance your editing experience if wanted.

**Will Keep on updating the project as I learn and get better at text editing
software.** -Tack
